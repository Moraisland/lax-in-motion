# LAX in Motion

Animated LAX passenger traffic stories and bilingual chart tutorials.

The complete editable project is in `site-source.zip`. Extract it and open the `lax-in-motion` folder to edit the site. The public site is built from `lax-in-motion/docs` inside this archive.

To publish an update, replace `site-source.zip` on the `main` branch with the revised project archive, preserving the folder structure. The GitHub Pages workflow deploys the update automatically.

Includes RacingBars 0.5.0 and its MIT license. The source CSV and all chart assets are included.
